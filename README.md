# Portfolio personal – Lucas Frontera

Portfolio personal desarrollado con HTML y CSS para presentar mi formación, conocimientos técnicos y proyectos relacionados con la administración de sistemas informáticos, redes y servidores.

## 🌐 Versiones

- **Español:** https://lufro404.github.io/
- **Français:** https://lufro404.github.io/fr/

## 📋 Contenido

El portfolio está organizado en las siguientes secciones:

- Sobre mí: presentación personal y formación.
- Proyectos: prácticas y proyectos de administración de sistemas.
- Habilidades: tecnologías y herramientas utilizadas.
- Trayectoria: formación académica y experiencia.
- Contacto: correo electrónico y GitHub.

## 💻 Proyectos destacados

- Servidor web en AWS EC2 con Ubuntu Server, Apache y HTTPS.
- Controlador de dominio con Samba AD DC.
- Despliegue de servicios mediante Docker y Docker Compose.
- Configuración de redes, gateway y copias de seguridad.
- Servicios de red en Linux con BIND9, Postfix, Dovecot y Ejabberd.
