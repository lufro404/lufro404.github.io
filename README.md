# Lucas Frontera Alloza — Personal Portfolio

Personal portfolio website showcasing my education, technical skills, projects and professional interests in IT systems administration, networking and cloud infrastructure.

**Website:** [lufro404.github.io](https://lufro404.github.io)

## Languages

The portfolio is available in three languages:

- **Spanish:** Main version (`/`)
- **English:** `/en/`
- **French:** `/fr/`

Each version includes a language selector to switch between them.

## Sections

- **About me:** Personal introduction and current studies.
- **Projects:** Practical work involving AWS, Samba AD DC, Docker, Linux services, network administration and programming in C.
- **Skills:** Operating systems, networking, virtualisation, services, web development and cloud technologies.
- **Education:** Academic background and training.
- **Languages:** Spanish, English and French.
- **Career objective:** Professional goals.
- **Contact:** Email, GitHub, LinkedIn and CV download.

## CV download

The CV is available as a PDF in each language and can be downloaded from the **Contact** section of the corresponding version of the website:

| Website version | CV file |
| --- | --- |
| Spanish (`/`) | `CV_Lucas_Frontera_Alloza_ES.pdf` |
| English (`/en/`) | `CV_Lucas_Frontera_Alloza_EN.pdf` |
| French (`/fr/`) | `CV_Lucas_Frontera_Alloza_FR.pdf` |

The three CV files are adapted to each language and are stored in the root of the repository. To update a CV, replace the PDF with the same file name and commit the change.

## Design

The website follows a clean, responsive design combining editorial typography with technical details.

Key features include:

- Responsive layout for desktop and mobile devices.
- Mobile navigation with a hamburger menu.
- Multilingual navigation.
- Project cards and technical skill sections.
- CV download link integrated in the contact section.
- Accessible navigation and reduced-motion support.

## Updating the website

1. Edit the files in the repository (or upload the new versions with **Add file → Upload files**).
2. Commit the changes to the `main` branch.
3. GitHub Pages publishes the new version automatically. Check the **Actions** tab, and wait for the deployment to finish before making further changes.
